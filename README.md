## 🔐 常用 Git 命令速查表

### 每天都要用的（已学 ✅）
```bash
git status              # 看看现在仓库是什么状态
git add .               # 把所有改动加入暂存区
git commit -m "说明"     # 提交存档（写清本次改了什么）
git push                # 同步到 GitHub
git pull                # 从 GitHub 拉取最新（换电脑时用）
```

### 以后会学到的（先眼熟）
```bash
git branch 分支名        # 建分支
git checkout -b 新分支   # 新建并切换
git log --oneline       # 查看提交历史
```

### Markdown 速成（写笔记够用）
```markdown
# 一级标题    ## 二级标题
**加粗**      *斜体*
- 列表项     1. 编号列表
[链接文字](网址)    ![图片说明](图片地址)
> 引用        `代码`
```
