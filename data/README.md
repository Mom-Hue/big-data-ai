# 🗄️ 数据集目录

本目录用于存放课程练习所需的数据集。

## 使用规范

- **大文件不入库**：超过 10MB 的数据文件（`.csv` / `.xlsx` / `.parquet` 等）已在 `.gitignore` 中忽略，请勿强行提交。
- **需要共享数据时**：在下方记录数据来源链接，而非直接提交文件。
- 小规模示例数据（< 1MB）可直接放入本目录。
