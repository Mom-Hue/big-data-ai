# 01 变量与数据类型

> 所属课次：阶段一 · 第 1 次课 ｜ 前置概念：无 ｜ 后续概念：字符串与格式化、输入与输出

## 一句话理解

变量是给数据起名字的"盒子"，数据类型决定了盒子里能装什么。

## 为什么需要它

写代码本质上是在"存数据、算数据"。如果每次都用死数字，代码就没法复用。变量让你把 `20`、`"Mom-Hue"` 这样的数据先存起来、起个名字，之后反复调用——就像新闻里给采访对象起个化名，正文里一直用这个名字指代他。而数据类型决定了这个盒子能装文本、整数还是小数，装错了会出 bug。

## 核心语法

```python
# 变量：给数据起名字（等号 = 是"赋值"，把右边的值装进左边的盒子）
name = "Mom-Hue"      # 字符串 str：文本，要加引号
age = 20              # 整数 int：计数、年龄
height = 1.68         # 浮点数 float：小数
is_student = True     # 布尔 bool：只有 True / False

# 用 f-string 把变量放进一句话（f 开头，{} 里写变量名）
print(f"我叫{name}，今年{age}岁，身高{height}米，学生身份：{is_student}")
```

四种最常用的数据类型：

| 类型 | 中文名 | 例子 | 用途 |
|------|--------|------|------|
| `int` | 整数 | `18` | 计数、年龄 |
| `float` | 浮点数 | `3.14` | 小数 |
| `str` | 字符串 | `"你好"` | 文本 |
| `bool` | 布尔 | `True` / `False` | 判断真假 |

用 `type()` 查看某个值是什么类型：

```python
print(type(age))     # <class 'int'>
print(type(name))    # <class 'str'>
```

## 常见错误

1. **字符串漏加引号**：`name = Mom-Hue` → 报错。正确写法：`name = "Mom-Hue"`。
2. **整数和字符串直接相加**：`"年龄" + age` → 报错。应写成 `f"年龄{age}"` 或 `"年龄" + str(age)`。
3. **`=` 和 `==` 混淆**：`=` 是赋值（给盒子装东西），`==` 是比较（两个值是否相等）。

## 动手小练习

**题**：写三行代码，分别用变量保存你的学校名、专业名、入学年份，再用一行 `print` 把它们连成一句自我介绍。

**参考答案**：

```python
school = "西北民族大学"
major = "新闻学"
year = 2025
print(f"我在{school}读{major}，{year}年入学。")
```

## 与你专业的连接

以后做舆情分析，你会读入大量新闻文本（`str`）、统计词频（`int`）、记录情感倾向分（`float`）、判断是否命中关键词（`bool`）——这四种类型在第一个项目里就全部用上。
