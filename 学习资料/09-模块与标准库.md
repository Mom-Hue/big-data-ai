# 09 模块与标准库

> 所属课次：阶段一 · 第 3 次课 ｜ 前置概念：函数 ｜ 后续概念：第三方库与jieba分词

## 一句话理解

`import` 把别人写好的"工具箱"拿过来直接用。

## 为什么需要它

不用什么都自己造轮子。Python 自带一大批"标准库"：要随机抽样有 `random`，要看时间日期有 `datetime`，要数学运算有 `math`，要操作文件系统有 `os`。`import` 一下就能用，省下大量时间。

除了标准库，Python 生态还有成千上万的"第三方库"，它们的安装和使用方式类似，下一课就会讲到。

## 核心语法

```python
import random          # 导入随机模块
import math            # 导入数学模块

names = ["张三", "李四", "王五"]
print(random.choice(names))   # 从名单里随机抽一个

print(math.sqrt(16))          # 4.0：开平方

# 也可以只导入模块里的某一个东西
from datetime import date
print(date.today())           # 打印今天的日期
```

常用标准库：

| 模块 | 作用 |
|------|------|
| `random` | 随机数、随机抽样 |
| `math` | 数学函数 |
| `datetime` | 日期和时间 |
| `os` | 文件和路径操作 |

## 常见错误

1. **忘了 `import` 直接调用**：不写 `import random` 就 `random.choice(...)` → 报错 `NameError`。
2. **模块名拼错**：`import randm` → 报错 `ModuleNotFoundError`。名字要写对。
3. **自己的文件名和模块名重名**：比如把自己的脚本命名成 `random.py`，会干扰导入。别用标准库名字给文件起名。

## 动手小练习

**题**：从一份选题列表里用 `random` 随机抽一个作为"今日选题"，打印出来。

**参考答案**：

```python
import random

topics = ["开学季", "夜市经济", "地铁新线", "秋季招聘"]
print(random.choice(topics))
```

## 与你专业的连接

抽样调查时用 `random` 随机抽取受访者、记录采集时间用 `datetime`、批量整理文件用 `os`，做数据新闻都离不开标准库。下一课你会学到用 `pip` 安装"第三方库"，原理和 `import` 一样。
