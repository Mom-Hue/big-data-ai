## 一句话理解

NLP 让电脑"读懂"文字，文本预处理就是先把脏文本洗干净再喂给电脑。

## 为什么需要它

网上的新闻评论和微博文本，往往混着标点、表情、空格、重复的字（"哈哈哈哈哈"），还有大量没意义的词（"的""了""是"）。如果把这些原样扔给模型，它会抓不住重点。所以做情感分析、文本分类之前，必须先做一遍"清洗→分词→去停用词"的预处理，这是 NLP 的地基。

## 核心语法

标准三步：清洗（去标点）→ 分词（jieba）→ 去停用词（过滤无意义词）。

```python
# 需要先安装：pip install jieba
import re
import jieba

text = "今天天气真好！！我很喜欢看新闻，非常喜欢！！！"

# 第 1 步：清洗。只保留中文、英文、数字，去掉标点和表情符号
clean = re.sub(r"[^\u4e00-\u9fa5a-zA-Z0-9]", "", text)
print("清洗后：", clean)

# 第 2 步：分词。把一整句话切成一个个词
words = jieba.lcut(clean)
print("分词后：", words)

# 第 3 步：去停用词。过滤掉"我""很""的"这类对判断没帮助的词
stopwords = {"我", "很", "的", "了", "是", "和", "啊"}
useful = [w for w in words if w not in stopwords]
print("去停用词后：", useful)
```

运行后你会看到，剩下的关键词基本就是"天气""喜欢""看新闻"这些有信息量的词，标点和无意义词都被清理掉了。

## 常见错误

1. **不清理直接分词**：会把"！！"这种标点当成一个"词"切出来。正确做法是先用 `re.sub` 清洗。
2. **停用词表太随意**：只放几个词会漏，放太多又会误删有用词。可以搜"中文停用词表"下载现成的，存成文件逐行读入。
3. **清洗过度**：把数字、英文也全删了，遇到"iPhone15 发布会"这类词就切坏了。正则里要保留 `a-zA-Z0-9`。

## 动手小练习

**题**：给下面这句话做三步预处理，打印最后剩下的词。

```python
text = "哇！！这场比赛太精彩了，看得我热血沸腾！！！"
```

**参考答案**：

```python
import re
import jieba

text = "哇！！这场比赛太精彩了，看得我热血沸腾！！！"
clean = re.sub(r"[^\u4e00-\u9fa5a-zA-Z0-9]", "", text)
words = jieba.lcut(clean)
stopwords = {"我", "太", "的", "了", "得"}
useful = [w for w in words if w not in stopwords]
print(useful)   # 输出类似：['哇', '这场', '比赛', '精彩', '看', '热血沸腾']
```

## 与你专业的连接

舆情分析的第一步永远是预处理：把几万条评论里的脏文本洗干净、切好词，后续才能统计高频词、判断情感、给内容分类。这一步做不好，后面所有分析都会失真。
