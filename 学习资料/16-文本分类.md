# 16 文本分类

> 所属课次：阶段二 · 第 7 次课 ｜ 前置概念：NLP 与文本预处理 ｜ 后续概念：综合项目实战

## 一句话理解

文本分类是给一篇文章自动贴上"体育""财经""科技"这类固定标签。

## 为什么需要它

新闻编辑部每天收到海量来稿，如果靠编辑手动把每篇分到对应栏目，工作量巨大。文本分类能先让电脑学会"什么样的标题属于体育、什么样的属于财经"，之后新稿子一来就自动归档，编辑只需做最后的把关。你在 14 课学的预处理，就是这里的第一步。

## 核心语法

思路：先把文字转成数字（TF-IDF），再交给分类模型学习。下面用新闻标题分类演示。

```python
# 需要先安装：pip install scikit-learn
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB

# 训练数据：标题 + 它属于哪个栏目（人工标好的答案）
titles = [
    "国足今晚迎战日本队",
    "NBA总决赛正式打响",
    "央行宣布降息0.5个百分点",
    "A股三大指数集体上涨",
    "新款手机发布售价公布",
    "人工智能大模型再突破",
]
labels = ["体育", "体育", "财经", "财经", "科技", "科技"]

# 第 1 步：把文字转成数字向量（TF-IDF 会衡量每个词的重要程度）
vec = TfidfVectorizer()
X = vec.fit_transform(titles)

# 第 2 步：训练分类模型
model = MultinomialNB()
model.fit(X, labels)

# 第 3 步：预测新标题属于哪个栏目
new_titles = ["刘翔现身田径场", "芯片公司发布财报"]
X_new = vec.transform(new_titles)      # 注意：这里用 transform，不是 fit_transform
print(model.predict(X_new))
```

结果应该输出 `['体育' '科技']`。关键在于：预测新文本时必须复用同一个 `vec`，否则词表对不上。

## 常见错误

1. **对新数据用 `fit_transform`**：`vec.transform(new)` 才是对的。用 `fit_transform` 会重新学词表，导致训练和预测的维度不一致而报错。
2. **每个类别的样本太少**：一个栏目只有 1 条标题，模型学不到规律。每个类别最好有几十条以上。
3. **训练文本没清洗**：标点、多余空格会变成"假词"干扰判断，最好先做一遍 14 课学的预处理。

## 动手小练习

**题**：在训练数据里再加两条标题（一条体育、一条财经）和对应标签，然后预测 `["新能源车企发布新车"]` 属于哪个栏目。

**参考答案**：

```python
titles += ["乒乓球世锦赛开幕", "黄金价格创新高"]
labels += ["体育", "财经"]
vec = TfidfVectorizer()
X = vec.fit_transform(titles)
model = MultinomialNB()
model.fit(X, labels)
print(model.predict(vec.transform(["新能源车企发布新车"])))   # 输出：['科技']
```

## 与你专业的连接

新闻自动分栏、内容打标签、推荐系统给文章归类，用的都是文本分类。以后做数据新闻或去新媒体平台工作，你常会遇到"给海量稿件自动打标签"的需求，这就是你的工具。
