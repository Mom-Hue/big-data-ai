# 15 情感分析

## 一句话理解

情感分析是判断一段文字的态度是正面、负面还是中性。

## 为什么需要它

一条突发新闻发出去，评论区可能有几千条留言。媒体机构想知道：读者总体是支持还是反对？负面情绪在哪个时间段爆发？人工一条条看根本来不及。情感分析程序能自动给每条评论打个"情感分"，你再用 pandas 汇总，几分钟就能看出一场舆论的整体风向。

## 核心语法

snownlp 是最容易上手的中文情感分析库，`sentiments` 会返回 0 到 1 之间的分数，越接近 1 越正面。

```python
# 需要先安装：pip install snownlp
from snownlp import SnowNLP

comments = [
    "这个政策太好了，必须支持！",
    "太差了，失望透顶。",
    "今天天气还行吧。",
]

# 逐条打分并判断倾向
for c in comments:
    score = SnowNLP(c).sentiments   # 0~1，越大越正面
    if score > 0.6:
        label = "正面"
    elif score < 0.4:
        label = "负面"
    else:
        label = "中性"
    print(f"{c} → 得分 {score:.2f}，倾向：{label}")
```

运行结果大致是：第一条"正面"、第二条"负面"、第三条"中性"。用两个阈值（0.4 和 0.6）而不是简单 0.5 一刀切，能减少边界误判。

## 常见错误

1. **用 0.5 一刀切**：得 0.51 判正面、0.49 判负面，太武断。留出中间"中性"区间（如 0.4~0.6）更稳妥。
2. **指望它读懂反讽**：snownlp 主要靠词表，像"这新闻真'棒'啊"这种反话可能误判成正面。涉及敏感判断时人工抽检一下。
3. **忘记安装**：`from snownlp import SnowNLP` 报错，多半是没先 `pip install snownlp`。

## 动手小练习

**题**：对下面三条评论做情感分析，打印每条的得分和倾向。

```python
comments = ["涨得漂亮，开心！", "又跌了，烦死了。", "就那样吧。"]
```

**参考答案**：

```python
from snownlp import SnowNLP

for c in comments:
    score = SnowNLP(c).sentiments
    label = "正面" if score > 0.6 else ("负面" if score < 0.4 else "中性")
    print(f"{c} → {score:.2f}，{label}")
```

## 与你专业的连接

舆情监测的核心指标之一就是"情感倾向占比"：某条新闻的评论里正面、负面各占多少，负面情绪是否在上升。这能帮你做新闻传播效果评估、品牌公关预警，是传媒数据新闻的常见选题。
