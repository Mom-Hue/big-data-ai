# 02 字符串与格式化

> 所属课次：阶段一 · 第 1 次课 ｜ 前置概念：变量与数据类型 ｜ 后续概念：文件读写与编码

## 一句话理解

字符串是装文本的盒子，格式化是把变量"贴"进一段文字里的方法。

## 为什么需要它

新闻工作天天和文字打交道：标题、导语、正文、评论，在 Python 里它们都是字符串 `str`。光会存还不够——你还要会从标题里切出前几个字做短标题、把采访对象的名字和年龄塞进一句话、判断某篇稿子里有没有出现某个词。这些都要靠字符串方法和 f-string 格式化来完成。

## 核心语法

```python
title = "我市今天天气晴朗"

# 1. 索引与切片：从 0 开始数，[起:止] 是"取左不取右"
print(title[0])        # 我
print(title[0:2])      # 我市
print(title[-2:])      # 晴朗（负数从右边往回数）

# 2. 常用方法
print(len(title))                  # 8：统计字符个数
print(title.replace("晴朗", "多云"))  # 替换：把"晴朗"换成"多云"
print("晴天" in title)             # False：判断是否包含某个词

# 3. f-string：把变量放进一句话（f 开头，{} 里写变量）
city = "兰州"
temp = 26
print(f"{city}今天气温{temp}度")
```

常用字符串方法一览：

| 写法 | 作用 | 例子结果 |
|------|------|----------|
| `s[0:2]` | 切片取前两个字 | `"我市"` |
| `len(s)` | 统计长度 | `8` |
| `s.replace(a, b)` | 替换 | 换词 |
| `"x" in s` | 判断是否包含 | `True/False` |
| `s.split(",")` | 按逗号切开 | 得到列表 |

## 常见错误

1. **引号不配对**：`name = "张三'` → 报错。开头和结尾的引号必须一样。
2. **下标越界**：`title[100]` → 报错 `IndexError`。下标最大只能到 `len(title) - 1`。
3. **用 `+` 拼数字和字符串**：`"气温" + temp` → 报错。应写成 `f"气温{temp}"`。

## 动手小练习

**题**：有一段新闻标题 `title = "我市新增三条地铁线路正式开通"`，请切出前 6 个字作为"短标题"打印出来；再用 f-string 输出一句话，包含城市名和温度两个变量。

**参考答案**：

```python
title = "我市新增三条地铁线路正式开通"
print(title[:6])          # 我市新增三条

city = "西安"
temp = 28
print(f"{city}今天最高气温{temp}度")
```
