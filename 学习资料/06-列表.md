## 一句话理解

列表是一个有序、可变的"大盒子"，用来装一串数据。

## 为什么需要它

一条新闻有很多关键词，一个栏目有几十条待办选题，一次抽样有几百个受访对象。列表让你把这些东西按顺序装在一起，之后可以随意增、删、改、查，还能配合循环逐个处理。

## 核心语法

```python
# 创建列表：方括号 []，元素用逗号隔开
keywords = ["时政", "民生", "教育"]

# 增删改查
keywords.append("体育")     # 追加：加到末尾
keywords[0] = "政务"        # 改：把第 0 个换成"政务"
keywords.remove("民生")     # 删：按值删除
print(keywords[1])          # 查：按位置取
print(len(keywords))        # 长度：列表里有几个元素

# 配合循环遍历
for k in keywords:
    print(k)
```

常用列表操作：

| 写法 | 作用 |
|------|------|
| `list.append(x)` | 末尾追加 |
| `list.insert(i, x)` | 插到指定位置 |
| `list.remove(x)` | 删除某个值 |
| `list.pop()` | 弹出末尾元素 |
| `len(list)` | 元素个数 |
| `list.sort()` | 排序 |

## 常见错误

1. **下标越界**：列表只有 3 个元素却写 `keywords[5]` → 报错 `IndexError`。下标从 0 到 `len-1`。
2. **删除不存在的值**：`keywords.remove("体育")` 但里面没有"体育" → 报错 `ValueError`。
3. **把位置当成从 1 开始**：`keywords[1]` 是第 2 个元素，不是第 1 个。

## 动手小练习

**题**：建一个"本周选题"列表，先加入三个选题，再追加一个、删掉一个，最后打印出列表长度和第一个选题。

**参考答案**：

```python
topics = ["开学第一课", "地铁新线", "夜市经济"]
topics.append("秋季招聘")      # 追加
topics.remove("地铁新线")      # 删除
print(len(topics))             # 3
print(topics[0])               # 开学第一课
```
