# 05 循环

> 所属课次：阶段一 · 第 2 次课 ｜ 前置概念：条件判断 ｜ 后续概念：列表、字典与集合、函数

## 一句话理解

`for` 遍历一串东西，`while` 在条件成立时反复干活。

## 为什么需要它

一篇稿子有几百个词，一条热搜下有几千条评论，靠手工一条条处理不现实。循环让程序把"同一件事"重复执行，你写一次，它做千百次——这是计算机最擅长、也最该交给它做的事。

## 核心语法

```python
# for 循环：遍历一串数字或一个列表
for i in range(5):
    print(i)          # 0 1 2 3 4（注意从 0 开始，到 4 结束）

words = ["新闻", "采访", "写作"]
for w in words:
    print(w)

# while 循环：条件成立就一直做
count = 0
while count < 3:
    print("再读一遍")
    count += 1        # 每次 +1，别忘，否则会死循环
```

两种循环怎么选：

| 场景 | 用哪个 |
|------|--------|
| 知道要遍历哪些东西（列表、范围） | `for` |
| 不知道次数，靠条件停止 | `while` |

## 常见错误

1. **缩进不对**：循环体必须比 `for`/`while` 缩进一级，否则不执行或报错。
2. **while 忘了改条件**：`while count < 3:` 里没有 `count += 1` → 死循环，程序卡住。
3. **把 `range(5)` 当成 1~5**：`range(5)` 是 `0 1 2 3 4`，共 5 个数，从 0 开始。

## 动手小练习

**题**：有一段文本 `text = "我们的新闻记录着时代的声音"`，请用 `for` 循环统计里面出现了多少个"的"字，并打印结果。

**参考答案**：

```python
text = "我们的新闻记录着时代的声音"
count = 0
for ch in text:
    if ch == "的":
        count += 1
print(count)   # 2
```
