## 一句话理解

机器学习是让电脑从大量数据里自己找出规律，而不是靠人一条条写规则。

## 为什么需要它

新闻行业每天产出海量内容：几万条标题、几十万条评论。如果让人工判断"这条属于体育还是财经""这条评论是夸还是骂"，既慢又贵。机器学习的思路是：先拿一批已经标好答案的历史数据让电脑"学习"，它自己总结出规律，之后面对新内容就能自动给出判断。你之前学的字典、pandas，正好用来装这些数据。

## 核心语法

机器学习最常见的三步：拿数据 → 训练（fit）→ 预测（predict）。下面用 scikit-learn 自带的鸢尾花数据走一遍。

```python
# 需要先安装：pip install scikit-learn
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier

# 第 1 步：拿数据。X 是特征（每朵花的 4 个数字），y 是标签（3 种花名编号）
iris = load_iris()
X = iris.data
y = iris.target

# 第 2 步：训练。让模型"看"数据，自己总结规律
model = DecisionTreeClassifier()
model.fit(X, y)

# 第 3 步：预测。给一朵新花的数据，猜它是哪一种
new_flower = [[5.1, 3.5, 1.4, 0.2]]
result = model.predict(new_flower)
print(f"预测结果：{result[0]}，花名：{iris.target_names[result[0]]}")
```

机器学习任务分几大类：

| 任务类型 | 做什么 | 新闻里的例子 |
|---------|--------|-------------|
| 分类 | 把数据分到固定几类 | 新闻标题分栏目（体育/财经/科技） |
| 回归 | 预测一个连续数字 | 预测某条新闻的阅读量 |
| 聚类 | 把相似数据自动归堆 | 把相似读者评论聚成几类观点 |

## 常见错误

1. **跳过训练直接预测**：没执行 `model.fit(X, y)` 就调用 `model.predict()`，会报"模型还没训练"的错误。必须先训练。
2. **把特征和标签搞混**：`X` 是"用来判断的依据"，`y` 是"要猜的答案"。把 `fit(y, X)` 写反，结果就乱了。
3. **以为 AI 会"思考"**：模型只是从数据里学到统计规律，数据里没有的东西它不会凭空知道。

