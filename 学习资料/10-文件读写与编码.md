## 一句话理解

用 `open` 把数据存进文件，需要时再读出来继续用。

## 为什么需要它

采集到的新闻数据不能只存在内存里，程序一关就没了。写进文件（比如 `.txt`）能长期保存、也能交给别人或别的程序使用。读中文文件时一定要指定编码 `utf-8`，否则会乱码。

## 核心语法

```python
# 写文件："w" 表示写入（会覆盖原内容）
with open("新闻.txt", "w", encoding="utf-8") as f:
    f.write("这是第一篇新闻\n")
    f.write("这是第二篇新闻\n")

# 读文件："r" 表示读取
with open("新闻.txt", "r", encoding="utf-8") as f:
    text = f.read()      # 一次性全读进来
    print(text)

# 逐行读：直接遍历文件，一行行取
with open("新闻.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip() 去掉行尾的换行符
```

打开模式：

| 模式 | 含义 |
|------|------|
| `"r"` | 只读（文件不存在会报错） |
| `"w"` | 写入（会覆盖原内容） |
| `"a"` | 追加（写在末尾，不覆盖） |

## 常见错误

1. **不写 `encoding="utf-8"`**：读中文文件 → 乱码或报错 `UnicodeDecodeError`。
2. **文件不存在还读**：`open("没这个.txt", "r")` → 报错 `FileNotFoundError`。先确认路径。
3. **用 `"w"` 覆盖了原文件**：想保留旧内容却用了 `"w"`，结果被清空。想追加请用 `"a"`。

## 动手小练习

**题**：把三条新闻标题写入 `标题.txt`，再从文件里逐行读出来打印。

**参考答案**：

```python
titles = ["我市今日晴", "地铁新线开通", "夜市经济回暖"]

with open("标题.txt", "w", encoding="utf-8") as f:
    for t in titles:
        f.write(t + "\n")

with open("标题.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```
