## 一句话理解

`def` 把一段代码打包成"工具"，起个名字，以后随用随调。

## 为什么需要它

"判断一篇稿子是长稿还是短稿"这个逻辑，可能要在十个地方用到。复制粘贴十遍又乱又难改。把它写成一个函数，起个名字，以后一行就能调用；要改逻辑也只改一处。函数让代码从"写一遍用一遍"变成"写一次用无数次"。

函数还能接收多个参数、返回多个结果，但刚开始先记住"输入参数、输出返回值"这一条主线就够了。

## 核心语法

```python
# def 定义函数，括号里是参数，return 把结果交回去
def judge_length(count):
    if count > 2000:
        return "长稿"
    elif count > 800:
        return "中稿"
    return "短稿"

print(judge_length(3000))  # 长稿
print(judge_length(500))   # 短稿
```

三个关键点：

| 概念 | 含义 | 例子 |
|------|------|------|
| 参数 | 调用时传进去的数据 | `count` |
| 返回值 | 函数算完交回的结果 | `return "长稿"` |
| 调用 | 使用函数的那一行 | `judge_length(3000)` |

## 常见错误

1. **忘了 `return`**：函数里算了半天却不 `return`，调用后拿到的是 `None`。
2. **定义完忘了调用**：只写 `def` 不写调用，程序啥也不输出——函数要"叫"它才动。
3. **参数和返回值分不清**：参数是"输入"，`return` 是"输出"，别把打印当返回。

## 动手小练习

**题**：写一个函数 `format_title(title)`，传入一篇新闻的标题，返回加好框的格式 `【标题】`，并调用它打印结果。

**参考答案**：

```python
def format_title(title):
    return f"【{title}】"

print(format_title("我市今日晴"))   # 【我市今日晴】
```
