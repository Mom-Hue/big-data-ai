# 03 输入与输出

> 所属课次：阶段一 · 第 1 次课 ｜ 前置概念：变量与数据类型 ｜ 后续概念：条件判断

## 一句话理解

`input()` 把用户敲进来的内容读进程序，`print()` 把结果展示出来。

## 为什么需要它

程序不能只会闷头自己算，还要会"问"和"答"。比如你想写一个小工具，先问记者"这篇稿子有多少字？"，读进来之后再回他一句"已记录"。问就是 `input()`，答就是 `print()`，一问一答，程序就"活"了。

要特别记住：`input()` 读进来的永远是字符串。哪怕你敲的是 `20`，也得先用 `int()` 转成数字才能做加减——这个坑下一课还会遇到。

## 核心语法

```python
# input()：从键盘读入内容，返回的一定是字符串 str
name = input("请输入你的名字：")
print("你好，" + name)

# input 读进来的是字符串，做数学前要先转类型
age = int(input("请输入年龄："))   # int() 把字符串转成整数
print(age + 1)                     # 转成数字才能做加法

# print() 一次输出多个东西，用逗号隔开（会自动加空格）
print("名字", name, "年龄", age)
```

常用输入输出函数：

| 函数 | 作用 | 注意 |
|------|------|------|
| `input(提示语)` | 读入一行输入 | 返回字符串 |
| `print(值)` | 打印输出 | 可输出多个值 |
| `int(字符串)` | 转整数 | 字符串要是数字 |
| `float(字符串)` | 转小数 | 字符串要是小数 |
| `str(数字)` | 转字符串 | 拼接时用 |

## 常见错误

1. **忘了 input 返回的是字符串**：`age = input("年龄：")` 后直接 `age + 1` → 报错。正确写法：`int(input("年龄：")) + 1`。
2. **print 里用 `+` 拼数字和字符串**：`print("年龄" + age)` → 报错。改成 `print("年龄", age)` 或 f-string。
3. **`int()` 接了非数字**：输入"二十"时 `int("二十")` → 报错。要先保证输入的是数字。

## 动手小练习

**题**：写一个"采访登记"小程序，依次读入受访者姓名和年龄，再用一行 `print` 输出一句完整的登记信息。

**参考答案**：

```python
name = input("请输入受访者姓名：")
age = int(input("请输入受访者年龄："))
print(f"已登记：{name}，{age}岁")
```
