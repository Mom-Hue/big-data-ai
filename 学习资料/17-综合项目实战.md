# 17 综合项目实战

> 所属课次：阶段二 · 第 8 次课 ｜ 前置概念：情感分析、文本分类 ｜ 后续概念：无

## 一句话理解

把预处理、文本分类、情感分析串成一条完整的文本分析流水线。

## 为什么需要它

前面几课学的是"零件"：分词、分类、情感打分。但真实工作里，你要处理的是"一整条流水线"——读入一批新闻数据，先给稿件分类，再对读者评论做情感分析，最后汇总出一份舆情报告。这一课就带你把这些零件装成一台能跑的机器。

## 核心语法

下面这个小项目走完整条流程：准备数据 → 训练分类器 → 给新标题分类 → 给评论做情感分析。

```python
# 需要先安装：pip install pandas scikit-learn snownlp
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from snownlp import SnowNLP

# 第 1 步：准备数据（模拟从文件读入的新闻稿）
news = [
    {"标题": "国足今晚迎战日本队", "栏目": "体育"},
    {"标题": "央行宣布降息", "栏目": "财经"},
    {"标题": "新款手机发布", "栏目": "科技"},
    {"标题": "NBA总决赛打响", "栏目": "体育"},
    {"标题": "A股集体上涨", "栏目": "财经"},
    {"标题": "AI大模型突破", "栏目": "科技"},
]
df = pd.DataFrame(news)

# 第 2 步：训练一个标题分类器（文本分类）
vec = TfidfVectorizer()
model = MultinomialNB()
model.fit(vec.fit_transform(df["标题"]), df["栏目"])

# 第 3 步：对新标题自动分类
new_title = ["芯片公司发布财报"]
pred = model.predict(vec.transform(new_title))
print("新标题分类为：", pred[0])

# 第 4 步：对读者评论做情感分析
comments = ["涨得好，开心！", "又跌了，失望。", "比赛太精彩了！"]
for c in comments:
    score = SnowNLP(c).sentiments
    label = "正面" if score > 0.6 else ("负面" if score < 0.4 else "中性")
    print(f"{c} → {label}（{score:.2f}）")
```

整个流程一句话概括：**先分类定栏目，再打分看情绪**，两条支线共用同一批数据。

## 常见错误

1. **步骤顺序乱**：没训练分类器就去分类新标题，会报错。一定要先 `fit` 再 `predict`。
2. **分类和情感搞混对象**：分类是给"稿件标题"贴栏目标签，情感是给"读者评论"打正负分，别拿错数据去喂。
3. **复用错词表**：分类新标题时要用同一个 `vec.transform`，否则训练和预测的维度对不上。

## 动手小练习

**题**：在 `news` 列表里再加一条 `{"标题": "乒乓球世锦赛开幕", "栏目": "体育"}`，重新训练后，预测 `["我国选手夺得乒乓球冠军"]` 属于哪个栏目。

**参考答案**：

```python
news.append({"标题": "乒乓球世锦赛开幕", "栏目": "体育"})
df = pd.DataFrame(news)
vec = TfidfVectorizer()
model = MultinomialNB()
model.fit(vec.fit_transform(df["标题"]), df["栏目"])
print(model.predict(vec.transform(["我国选手夺得乒乓球冠军"])))   # 输出：['体育']
```

## 与你专业的连接

这套"分类 + 情感"的流水线，就是一个小型舆情监测系统的雏形：自动给新闻分栏目，自动算出每类新闻下的评论情绪，最后汇总成一份"哪类新闻最受好评、哪类正在引发负面舆情"的分析报告——这正是数据新闻和舆情分析岗的日常。
