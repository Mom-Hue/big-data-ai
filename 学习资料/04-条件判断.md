# 04 条件判断

> 所属课次：阶段一 · 第 2 次课 ｜ 前置概念：输入与输出 ｜ 后续概念：循环

## 一句话理解

`if / elif / else` 让程序根据条件走不同的分支。

## 为什么需要它

新闻不是每篇都一样：稿子字数有没有超限、受访者是否达到可独立采访的年龄、一条评论是不是敏感内容，这些"如果……就……否则……"的判断逻辑，都要靠条件语句来实现。有了它，程序才不再是死脑筋，而会"看情况办事"。

判断还可以嵌套、组合：比如"字数超过 800 且栏目是时政"就用 `and` 把两个条件连起来，一次判断两件事。

## 核心语法

```python
score = int(input("请输入文章字数："))

if score > 2000:
    print("长稿")
elif score > 800:
    print("中稿")
else:
    print("短稿")
```

程序从上往下判断，命中哪条就执行哪条，其余跳过。常用的比较和逻辑运算：

| 写法 | 含义 |
|------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` `<` `>=` `<=` | 大于 / 小于 / 大于等于 / 小于等于 |
| `and` | 两个条件都成立 |
| `or` | 两个条件任一成立 |
| `not` | 取反 |

## 常见错误

1. **把 `=` 当 `==`**：`if score = 2000:` → 报错。判断相等必须用 `==`，`=` 是赋值。
2. **忘了冒号或缩进**：`if score > 2000` 后面漏掉 `:`，或分支里的代码没缩进，都会报错。
3. **多个条件用 `&` 连接**：`if a > 0 & b > 0` → 语义不对。应写 `if a > 0 and b > 0`。

## 动手小练习

**题**：读入受访者年龄，如果满 18 岁输出"可以独立接受采访"，否则输出"需要监护人陪同"。

**参考答案**：

```python
age = int(input("请输入受访者年龄："))
if age >= 18:
    print("可以独立接受采访")
else:
    print("需要监护人陪同")
```

## 与你专业的连接

舆情分级预警（负面占比超阈值就报警）、敏感词拦截、稿件自动分类，本质都是一串条件判断。下一课"循环"会让判断在成百上千条数据上反复执行。

把判断写成规则，程序就能替你做第一轮初审，把明显不合规的稿子先筛出来。
