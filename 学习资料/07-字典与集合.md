# 07 字典与集合

## 一句话理解

字典是"键—值"对照表，集合是自动去重的袋子。

## 为什么需要它

统计词频时，你想知道"每个词出现了几次"，这就需要一个词（键）对应一个次数（值）的对照表，这就是字典。想快速知道一篇稿子里用了哪些不同的词，把词丢进集合，重复的会自动消失。两者都是文本分析的基本功。

## 核心语法

```python
# 字典：花括号 {}，键: 值 成对出现
news = {"标题": "我市今日晴", "字数": 1200, "栏目": "民生"}
print(news["标题"])       # 我市今日晴（按"键"取值）
news["作者"] = "小李"     # 新增一个键值对

for k, v in news.items():  # 同时拿到键和值
    print(k, v)

# 集合：自动去重，没有顺序
words = {"新闻", "新闻", "采访"}
print(words)               # 去重后可能是 {'新闻', '采访'}（顺序不保证）
```

字典与集合对比：

| | 字典 dict | 集合 set |
|---|---|---|
| 样子 | `{"键": 值}` | `{元素}` |
| 特点 | 键唯一，值可重复 | 元素唯一、自动去重 |
| 用途 | 词→次数、字段→内容 | 去重、求交集 |
| 空集合写法 | `{}` | `set()`（`{}` 是空字典） |

## 常见错误

1. **访问不存在的键**：`news["作者"]` 但还没有这个键 → 报错 `KeyError`。用 `news.get("作者", "未知")` 更安全。
2. **空集合写成 `{}`**：`{}` 其实是空字典，空集合要写 `set()`。
3. **键不能用列表**：`{[1, 2]: "a"}` → 报错。字典的键必须是不可变的（字符串、数字等）。

## 动手小练习

**题**：统计一句话 `s = "新闻是新闻人写新闻"` 里每个字出现的次数，用字典保存结果并打印。

**参考答案**：

```python
s = "新闻是新闻人写新闻"
counts = {}
for ch in s:
    if ch in counts:
        counts[ch] += 1
    else:
        counts[ch] = 1
print(counts)
```

## 与你专业的连接

词频统计是文本分析的第一步，字典就是它的底层容器；集合用来给关键词去重、求两篇报道的共有词。到阶段二的"AI 与机器学习基础"，你会看到很多特征都是用字典来组织的。
