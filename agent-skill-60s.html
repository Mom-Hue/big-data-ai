一分钟掌握 Agent Skill

看下方 6 张卡片，每张 10 秒 → 底部做 5 道测试题检验掌握度

60 秒倒计时 · 建议按顺序阅读
① 10s

Agent 是什么？

Agent（智能体） = 能"理解目标 → 自主规划 → 调用工具 → 完成行动"的 AI。它不止会聊天，还会像人一样拆解任务、执行步骤（如查数据、写代码、发消息）。

类比：一个有手有脚、会思考的员工
② 20s

Skill 是什么？

Skill（技能） = 一段"说明书 + 模板"，把某类任务的专业做法、步骤、话术固化下来。Agent 遇到对应任务时，Skill 教它"这件事该怎么做才专业"。

本质：SKILL.md（技能说明文档）+ 可能附带的脚本 / 示例 / 资源文件。

类比：给员工的《岗位操作手册》
③ 30s

为什么把两者结合？

没有 Skill：Agent 每次都"临场发挥"，质量不稳定。
有了 Skill：把专家经验沉淀成可复用技能包 → 稳定、高效、可分享。Agent 是身体，Skill 是技能库。

一次沉淀，处处复用
④ 40s

一个 Skill 长什么样？

典型结构（目录即一个技能包）：

my-skill/
  ├─ SKILL.md　← 核心：描述 + 触发条件 + 操作步骤
  ├─ scripts/　← 可选：辅助脚本
  └─ references/　← 可选：资料、模板

SKILL.md 开头常用 YAML 元信息写明技能名称与适用场景（description），供 Agent 匹配。

⑤ 50s

Agent 如何使用 Skill？

① 识别：听懂用户请求 → ② 匹配：用"技能描述"比对任务 → ③ 加载：读取对应 SKILL.md → ④ 执行：按技能步骤完成任务。

全程对用户透明，技能让 AI 从"会的"变成"专业的"。

触发 = 描述匹配，无需手动开关
⑥ 60s

一句话总结 + 上手建议

"Agent Skill = 把专业工作流打包，让 AI 按手册办事。"

想上手？从复现一个已有技能开始：读它的 SKILL.md → 看它怎么描述触发条件 → 试着自己写一个 5 行的迷你技能（如"写会议纪要"）。
