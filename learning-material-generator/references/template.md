# 概念学习资料 · 统一模板

每个概念生成一个独立 Markdown 文件，放入仓库 `学习资料/` 目录，文件名与 `concept-list.md` 的"文件名"列严格一致（格式：`{两位序号}-{概念名}.md`）。

## 文件结构（小节顺序固定）

1. 一级标题：`# {序号} {概念名}`
2. 元信息引用块（紧跟标题）：
   > 所属课次：阶段X · 第 N 次课 ｜ 前置概念：A、B ｜ 后续概念：C、D
   （前置/后续必须与 `concept-list.md` 一致；没有则写"无"）
3. `## 一句话理解`：一句话（≤30 字）说清这个概念是什么
4. `## 为什么需要它`：用生活或新闻场景讲动机（2–4 句）
5. `## 核心语法`：最小可运行 Python 代码示例，关键行加中文注释；可附一张小表
6. `## 常见错误`：列 2–3 个新手必踩的坑（错误示例 + 正确写法）
7. `## 动手小练习`：1 道题 + 参考答案（代码块）
8. `## 与你专业的连接`：联系新闻/传媒场景，说明这个概念将来能用来做什么

## 写作要求

- 面向零基础中文学习者（新闻学专业、无编程经验）；
- 代码可运行、注释中文、代码内使用 ASCII 直引号（`"` `'`）；
- 每份 60–120 行，讲透即可，不堆砌；
- 概念名、前置/后续关系以 `concept-list.md` 为唯一事实来源。
