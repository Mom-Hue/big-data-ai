# 学习资料生成器（learning-material-generator）

本技能把"为一个概念写一份学习资料"这件事标准化，保证 17 个概念的产出结构统一、彼此可关联。

## 适用场景

- 为学习地图中的某个概念生成一份单页学习资料；
- 按概念清单批量生成全部概念资料；
- 维护概念目录页（学习资料/README.md）中的关系图与链接。

## 工作流程

1. **读取清单**：先读 `references/concept-list.md`，确认概念的序号、文件名、所属课次、前置/后续关系。
2. **读取模板**：读 `references/template.md`，严格按其中的小节顺序与写作要求产出。
3. **生成文件**：每个概念生成一个 Markdown 文件，放入仓库 `学习资料/` 目录，文件名与清单中的"文件名"列完全一致。
4. **保持一致**：文件头部元信息中的"前置/后续概念"必须与清单一致，不得自行改动概念之间的关系。
5. **更新目录**：新增或调整概念后，同步更新 `学习资料/README.md` 的目录与概念关系图（mermaid）。

## 写作红线

- 面向零基础中文学习者（新闻学专业、无编程经验）；
- 代码必须可运行，注释用中文，代码内一律使用 ASCII 直引号；
- 每份 60–120 行，讲透即可，不堆砌；
- 概念名、前置/后续关系以 `references/concept-list.md` 为唯一事实来源。

## 参考文件

- `references/template.md` —— 单份资料的统一模板；
- `references/concept-list.md` —— 17 个概念的权威清单与依赖关系。
