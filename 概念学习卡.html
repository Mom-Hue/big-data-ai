蓝卡 · 概念定义（是什么）

6 张
蓝 01

Agent Skill 是什么

一个包含 SKILL.md 的文件夹，把指令、脚本与资源打包，供 AI 按需加载。
  • 目录即技能，可版本管理、可移植
  • 把"通用助手"变成"领域专家"
📖 Anthropic 官方文档
蓝 02

Agent（智能体）

能理解目标 → 自主规划 → 调用工具 → 完成任务的 AI 系统。
  • 不止会聊天，还会执行多步行动
  • 类比：有手有脚、会思考的员工
📖 Claude 官方博客
蓝 03

Skill（技能）

把某类任务的专业做法固化成可复用的技能包。
  • 教 agent"这件事怎么做才专业"
  • 类比：岗位操作手册
📖 Claude 官方博客
蓝 04

SKILL.md

技能包中唯一必需的文件：YAML 元信息 + 操作指令。
  • 技能入口，agent 读取它执行任务
  • 正文建议分步指引 + 示例
📖 agentskills.io 规范
蓝 05

Frontmatter（元信息）

SKILL.md 顶部的 YAML 字段，name 与 description 必填。
  • name：小写字母/数字/连字符，≤64 字符
  • description：≤1024 字符，写清"做什么+何时用"
📖 Anthropic 官方文档
蓝 06

过程性知识

"怎么做一件事"的操作性知识，是技能要传递的核心。
  • 区别于"是什么"的事实性知识
  • 模型本身缺乏，需外部注入
📖 Claude 官方博客

橙卡 · 机制流程（怎么运作）

5 张
橙 07

渐进式披露

三层按需加载：描述 → 正文 → 资源。
  • 第 1 层：只加载 name + description（约 100 tokens）
  • 第 2 层：命中后读完整 SKILL.md
  • 第 3 层：执行中按需读 references / 跑 scripts
📖 Claude 官方博客
橙 08

发现 → 激活 → 执行

技能被使用的三步工作流。
  • 发现：启动时读所有技能的描述
  • 激活：任务匹配则读完整 SKILL.md
  • 执行：按指令操作并调用资源
📖 agentskills.io
橙 09

触发匹配

靠 description 判断"这个技能是否该用"。
  • 描述要同时含功能与使用场景
  • 无需手动开关，自动匹配
📖 Anthropic 官方文档
橙 10

何时创建技能

出现这些信号就该沉淀：重复粘贴同一套流程。
  • 反复把同一脚本/清单粘进对话
  • 说明文件从"事实"长成"流程"
📖 Claude Code 文档
橙 11

与 MCP 的关系

MCP 给"手"，Skill 给"方法"，二者互补。
  • MCP：智能体如何连上工具与数据
  • Skill：一件事该怎么做
📖 agentskills.io

绿卡 · 实践要点（怎么用）

5 张
绿 12

标准目录结构

SKILL.md（必需） + scripts/ references/ assets/（可选）。
  • 目录名 = 技能名 = name 字段
  • 按需增删可选目录
📖 agentskills.io 规范
绿 13

scripts/ 的用途

存放可执行代码，处理确定性强的操作。
  • 如解析 PDF、排序、批处理
  • 代码可运行，不必读入上下文
📖 Anthropic 官方文档
绿 14

references/ 的用途

存放按需读取的参考资料。
  • 如流程指南、API 文档、规范
  • 让 SKILL.md 保持精简
📖 Anthropic 官方文档
绿 15

安全审计

只用可信来源的技能，用前审计捆绑文件。
  • 警惕意外网络请求与异常文件访问
  • 外部 URL 拉取内容的技能风险高
📖 Anthropic 官方文档
绿 16

开放标准

Anthropic 2025-10 推出，2025-12 发布为开放标准。
  • 官网 agentskills.io，多工具支持
  • 写一次，跨产品复用
📖 agentskills.io
