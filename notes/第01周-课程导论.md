## 课堂笔记

### 1. 开发工具链
| 工具 | 作用 | 我的理解 |
|------|------|----------|
| Git | 版本控制 | 给代码"存档"，可回退、可同步 |
| Python | 编程语言 | 大数据/AI 最常用的语言 |
| VSCode | 代码编辑器 | 写代码的"笔记本" |
| GitHub | 云端仓库 | 代码的"网盘 + 日记本" |

### 2. Git 核心工作流（三步曲）
每次修改完代码/笔记，在仓库目录打开终端执行：
```bash
git add .          # 1. 把改动放进"暂存区"
git commit -m "说明" # 2. 存档（写清楚这次改了什么）
git push           # 3. 同步到 GitHub 云端
```

### 3. Agent Skill 是什么（一句话）
把"做某件事的专业流程"打包成文件夹（SKILL.md 说明书 + 脚本），AI 需要时自动加载 → 稳定、可复用。
