# 📝 课程笔记

这里存放《大数据与人工智能》每课笔记。**每学一课，就复制 `笔记模板.md` 建一个新文件。**

## 命名规范

```
第01周-课程导论.md
第02周-Python基础.md
第03周-数据结构.md
...
```

> 用两位数编号（01、02…）能让文件在 GitHub 上按顺序整齐排列。

## 目录内容

| 文件 | 说明 |
|------|------|
| [学习进度.md](学习进度.md) | 整个学期进度打卡表（勾选 + 链接） |
| [笔记模板.md](笔记模板.md) | 新建笔记前复制此模板 |
| [第01周-课程导论.md](第01周-课程导论.md) | 示例：第 1 周笔记 |
